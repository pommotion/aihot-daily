# 仓库目录与运行说明

本文依据 `pommotion/aihot-daily` 的 `0f0ffd9` 版本，以及 2026-10-22 只读查询到的 GitHub Pages 配置整理。站点配置后续可能变化；未能从仓库或配置确认的事项均标为「未确认」。

## 项目是什么

AI DAILY 是中文 AI 行业日报的静态网站。仓库保存首页和已经生成的每日日报 HTML，不是需要启动后端的应用。

- 首页使用内联 CSS 和原生 JavaScript，按 `REPORTS` 日期数组生成历史列表，并将「阅读今日日报」指向数组第一项。
- 日报正文和样式直接写在各自 HTML 中，无需数据库或运行时 API。
- 页面从 Google Fonts 加载字体；无法联网时会使用 CSS 中的后备字体，新闻原文链接也需要联网访问。
- 仓库没有依赖清单、构建脚本、自动化测试配置或 `.github/workflows/`。本地预览不需要 Node.js、`npm install`、API 密钥或 `.env`。

## 主要目录与文件

```text
aihot-daily/
├── README.md             # 简短的项目名称与署名
├── index.html            # 首页、历史日报日期列表和最新日报入口
├── reports/              # 按 YYYY-MM-DD.html 命名的日报静态页面
├── 2026-06-17.html        # 根目录另存的一份当日日报，不是首页入口
├── CNAME                 # GitHub Pages 自定义域名
└── docs/
    └── repo-guide.md     # 本说明
```

`reports/` 在上述版本中有 139 份日报，日期从 2026-05-20 到 2026-10-19，并非每个自然日都有文件。首页不扫描目录，而是使用手写在 `index.html` 中的 `REPORTS` 数组；仅添加 HTML 文件不会自动出现在首页。

根目录的 `2026-06-17.html` 与 `reports/2026-06-17.html` 是不同路径；首页历史列表使用后者。根目录这份文件的保留用途「未确认」，其中指向根目录前一天文件的旧链接可能无法打开。

## 本地安装与运行

### 1. 准备环境并获取仓库

需要 Git、现代浏览器，以及 Python 3（仅作为静态文件服务器，不是项目依赖）。以下命令假定使用支持 `python3` 的终端：

```sh
git clone https://github.com/pommotion/aihot-daily.git
cd aihot-daily
python3 --version
```

无需额外安装 Python 包，也无需配置密钥或环境文件。

### 2. 从仓库根目录启动预览

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

保持终端运行，在同一台机器的浏览器中打开：

- 首页：<http://127.0.0.1:8000/>
- 日报示例：<http://127.0.0.1:8000/reports/2026-10-19.html>

按 `Ctrl+C` 停止服务。端口被占用时，将命令与访问地址中的 `8000` 一起替换为其他空闲端口。

请从仓库根目录启动，不要从 `reports/` 启动。日报使用 `/` 和 `/reports/...` 这样的根路径链接，直接双击 HTML 或把站点挂在子路径下，导航可能失效。Python 自带服务器仅用于本地预览，不作为生产服务。

### 3. 检查是否正常

1. 首页显示历史日期列表，「阅读今日日报」打开列表中的最新日报。
2. 点击历史日期能打开对应正文，点击「返回首页」回到首页。
3. 检查日报中已有的前后日期导航；没有对应文件或未更新的历史链接可能失效。

首页列表为空时，先检查浏览器是否启用了 JavaScript；字体与预期不同时，检查 Google Fonts 的网络连接。仓库没有可直接运行的测试、格式检查或构建命令，上述步骤是本地人工冒烟检查。

若日后需要由维护者重新配置部署，应在仓库的 **Settings → Pages → Build and deployment** 核对「Deploy from a branch」、`main` 和 `/(root)`，并核对自定义域名及 HTTPS。此处只是说明现状，不要求本次执行这些操作。

其他静态托管平台理论上可直接托管这些文件，但须保留 `index.html`、`reports/` 的相对结构，并以站点根路径提供服务。其他平台的实际配置与发布命令「未确认」。

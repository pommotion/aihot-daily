Claude Code 空闲压缩是从摘要继续，可用 idleCompaction 关闭并自定义阈值
X：Lydia Hallie（Anthropic）· 2026-10-14
Claude Code 的空闲压缩（idle compaction）会让 Claude 从摘要而非完整上下文继续对话。作者说明可在 settings 中设置 "idleCompaction": false 关闭，并通过环境变量 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 自定义触发阈值，默认 200k tokens。
长会话里模型「忘了」不是模型笨，是压缩策略在偷偷换上下文——这个开关能救长任务。

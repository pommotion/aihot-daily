470 项实测：Agent 有 73% 的运行察觉文件冲突，却 0% 主动上报
Google AI · DEV · 2026-11-25
Google AI 开发者 Patrick Kelly 用 470 个任务实测，区分了 context rot 与 context drift：在 Gemini 3.8 Flash 和 Gemini Pro 的沙箱中，模型 73% 的运行里内部察觉到文件冲突，但 0% 主动告知用户；95%–100% 的情况下任务级状态与真实文件不一致。作者给出一个零成本的 MCP 冲突上报方案。
Agent 不会撒谎，但它默认不报坏消息——冲突检测得靠外挂工具强制抽查，别指望模型自觉。

Anthropic 复盘 Messages API 从 Python 迁到 Rust：每请求 CPU 降约 70%
Anthropic Research · 2026-11-25
Anthropic 复盘把 Messages API 从 Python 重写为 Rust 的过程，核心方法是用生产系统本身当校验器，靠真实流量对齐新旧实现的行为差异。该 API 流量从 2024 年初到 2026 年秋增长约 1800 倍，迁移后每请求 CPU 降低约 70%，首 token 中位时间缩短约 20%，全程未停服、未冻结功能开发。
重写服务最贵的一步是判定行为等价，用影子流量做差分比对，比补一堆单测更能兜住。
